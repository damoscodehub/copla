# Security Policy

## Supported versions

Security fixes are provided for the latest version on the `main` branch until a
versioned release policy is established.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability-reporting feature for this repository when it is enabled.
If that feature is unavailable, report the issue to damoscodehub@gmail.com with
the subject line `Copla security report`.

Include a clear description, affected version or commit, reproduction steps,
impact, and any suggested mitigation. A report will be acknowledged within
seven days. Public disclosure will be coordinated after a fix is available or a
reasonable mitigation is documented.
